# v1.2.0 release notes (prepared, unpublished)

- Publish the backend extension contract, strict opt-in structural assertions,
  explicit borrowing/length/replay capabilities, and `core.releaseString`.
- Add `serde.testing` token serialization and deserialization assertions, plus
  independent type-author and format-author dependency packages.
- Add opt-in JSON diagnostics with copied JSON-pointer paths, source locations,
  expected/actual context and bounded caller-provided storage. Managed parsing
  and low-level schema/adapter paths share the ordinary parser primitives.
- Lead documentation with managed result ownership, publish author guides and a
  capability matrix, and test docs and packaged consumers in CI.

Existing hook names, dispatch priority, convenience signatures, `Kind` / `Value`
variants and wire representations remain unchanged. Legacy permissive interface
predicates remain available. No new supported format is added.

Replay is explicit for opted-in backends; streaming union replay, map flatten,
other-format diagnostics and complete specification conformance are outside this
release. The next development priorities are executable fuzzing and conformance.
See [verification](v1.2.0-verification.md) for measured evidence and release gates.
